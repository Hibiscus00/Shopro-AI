## 执行摘要

## 一、项目概述与定位

### 1.1 项目定义

Shopro AI 是面向兴趣电商（抖音 / TikTok / 快手 / 小红书）及跨境电商（TikTok Shop / Temu / 独立站）商家的 **AIGC 全链路视频生产 SaaS**。平台以「商品即输入，AI 即产能」为核心理念，打通从卖点挖掘、脚本生成、数字人演绎、多语言适配到多平台分发的完整工作流。

系统基于 **React 18.3.1 + TypeScript 5.5.3 + Vite 5.4.1** 构建前端交互层，采用 **Supabase 2.103.1（Auth + PostgreSQL + Storage + Edge Functions）** 作为 BaaS 后端，通过 Deno Runtime 部署 10+ 服务端函数，统一封装 AI 聚合、视频任务、支付订单、微信回调等核心能力。AI 能力层接入 **Kling**（视频生成）、**Sora**（视频生成）、**MiniMax**（对话/文案）、**文心**（文本生成/卖点提取）等主流大模型，形成可实际运行的生产管线。

## 二、市场分析

### 2.1 行业背景与市场规模

全球兴趣电商 / 直播电商市场正处于爆发期。据行业数据，2025 年全球短视频电商市场规模已突破 **2 万亿美元**，其中：
- 抖音电商 GMV 超过 **3 万亿元人民币**
- TikTok Shop 全球 GMV 超过 **1000 亿美元**
- 快手电商 GMV 超过 **1 万亿元人民币**

在内容电商生态中，短视频是流量分发的核心载体。据测算，抖音平台每日新增短视频超 **10 亿条**，其中带货类视频占比超过 **30%**。数以百万计的商家需要持续产出高质量带货视频，形成了万亿级的视频生产服务市场。

当前市场玩家可分为四类，Shopro AI 的差异化定位如下：

| 竞争类别 | 代表产品 | 优势 | 劣势 | Shopro AI 的差异化 |

## 三、技术方案

### 3.1 系统架构总览

Shopro AI 采用 **云原生 BaaS + Edge Functions** 架构，实现高可用、低延迟、弹性扩缩容。

- **前端层**：React 18.3.1 + TypeScript 5.5.3 + Vite 5.4.1，包含官网宣传页（/landing）、登录/注册、首页总览、AI 工具箱、视频生成工作台、批量生成工作台、视频剪辑页、作品管理、素材库、数据看板、流量分析、爆款风格复刻、竞品爆款分析、知识库管理、商品管理、数字人库、视频模板库、积分与套餐、活动奖励、邀请有礼、竞品监控、直播高光提取、多平台发布、个人中心等 **15+ 业务页面**。
- **后端 BaaS**：Supabase 2.103.1，提供 Auth（邮箱注册/登录/密码重置）、PostgreSQL（用户、商品、素材、视频任务、订单等全量数据）、Storage（素材与海报文件存储）、Realtime（视频生成进度推送）。
- **服务端计算**：Supabase Edge Functions（Deno Runtime），封装 **10+ 核心接口**：ai-assistant（统一 AI 入口）、create-payment-order（微信支付订单）、wechat-payment-webhook（支付回调）、kling-video-create / kling-video-query（可灵视频生成）、sora-video-create（Sora 视频生成）、minimax-chat（MiniMax 对话）、wenxin-text-generation（文心文本生成）、phase3-assistant（Phase 3 智能助理）等。
- **AI 能力层**：Kling（视频生成）、Sora（视频生成）、MiniMax（对话/文案）、文心（文本生成/卖点提取），通过 INTEGRATIONS_API_KEY 统一密钥管理。
- **数据缓存与限流**：llm_cache（LLM 响应缓存 24 小时）、rate_limit_windows（数据库持久化限流窗口），降低重复生成成本 60% 以上。

### 3.2 核心技术模块详解

#### 3.2.1 AI 脚本生成工作台（四层 Prompt 流水线）

- **入口**：ai-assistant Edge Function
- **能力**：根据商品 URL 或手动录入信息，通过 Chain-of-Thought（CoT）提示词链，顺序调用四层 LLM 生成结构化分镜脚本：
  1. 商品信息提取（标题、主图、卖点、价格）
  2. 目标用户画像分析（年龄、地域、消费能力、痛点）
  3. 核心卖点提炼（35 个差异化卖点）
  4. 分镜脚本生成（场景、画面、台词、时长建议）
- **技术亮点**：
  - 内置 **llm_cache** 与 **rate_limit_windows**，相同商品 24 小时内复用结果，降低 60% 以上 API 调用成本；
  - 支持 **Server-Sent Events（SSE）** 流式响应，前端通过 src/lib/sse.ts 封装解析，实时展示生成进度；
  - 支持用户取消生成任务，释放 Edge Function 资源。

#### 3.2.2 多路异步音视频 AIGC 混剪引擎

- **数字人克隆**：集成 Kling / Sora 视频生成接口，支持用户上传照片或视频片段生成专属数字人模型，克隆完成后自动加入数字人库。
- **多语言口型对齐**：MiniMax 语音合成 + 数字人口型同步，支持中 / 英 / 泰 / 印尼 / 越等多语种，目标对齐准确率 > 95%。
- **异步队列**：视频生成任务写入 ideo_jobs / ideo_projects 表，前端通过轮询或 SSE 获取进度，支持断点续传与任务取消。
- **流式日志**：素材上传与视频生成过程中展示实时日志（文件名、百分比、当前处理步骤），缓解用户等待焦虑。

#### 3.2.3 数据看板与 A/B 测试

- **AB Test 引擎**：b_test_variants 表管理多版本脚本 / 封面 / 素材，自动追踪播放量、转化率、ROI。
- **数据可视化**：Recharts 绘制趋势图、雷达图，支持导出 Excel（xlsx） / PDF（jspdf）报告。
- **竞品分析**：competitors 表存储竞品账号数据，结合 AI 分析 API 生成爆款策略报告。

#### 3.2.4 积分与支付闭环

- **计费模型**：将 AI 能力拆分为细粒度积分消耗项（脚本 10 积分/次、视频渲染 50 积分/秒、数字人克隆 5000 积分、多语言翻译 100 积分/语种）。
- **支付集成**：微信支付全流程（create-payment-order  微信支付  wechat-payment-webhook 服务端验签  积分下发），通过 query-payment-status 前端轮询刷新订单状态。
- **邀请裂变**：invite_records 表持久化存储邀请关系，邀请人与被邀请人均获积分奖励。

### 3.4 安全与合规设计

- **前端零敏感密钥**：仅使用 VITE_SUPABASE_ANON_KEY，所有私钥（INTEGRATIONS_API_KEY、微信支付密钥、Kling/Sora/MiniMax API 密钥）存放于 Edge Function Secrets。

- **内容审核**：AI 生成链末端接入敏感词过滤库，违禁内容自动拦截。

## 九、超级个体选拔导向核心问答

> 本部分是计划书的核心增补内容，专门回答「超级个体选拔导向」下的五个关键问题。我们认为，未来的电商内容生产不再是团队与团队之间的竞争，而是「超级个体」与「超级个体」之间的竞争。Shopro AI 的使命，就是让每一个个体商家都成为超级个体。

### Q1：项目定位与解决的核心痛点

**项目定位**：

Shopro AI 不是传统意义上的 SaaS 工具提供商，而是 **超级个体内容产能基础设施**。我们的使命是将过去只有 MCN 机构、品牌方才能享有的团队级视频生产能力，以极低成本赋予每一个个体商家、个人创作者和小微工作室。

在抖音 / TikTok 的算法逻辑下，流量分配的核心权重是「内容生产效率  内容质量」。大商家有团队、有预算、有供应链，可以日更 10 条视频；小商家一个月未必能产出一条。Shopro AI 要做的，就是抹平这条产能鸿沟，让个体商家在起跑线上与大品牌平等竞争。

**解决的核心痛点**：

1. **产能不公（Production Inequality）**：
   - 大商家日更 10 条，小商家月更 1 条。算法对持续产出的账号给予更高权重，导致马太效应。
   - Shopro AI 的批量生成工作台支持 CSV 批量导入商品，一键生成 100 条差异化视频，让个体商家也能日更。

2. **技能鸿沟（Skill Gap）**：
   - 不会写脚本、不会剪辑、不会拍口播、不会找外籍演员这是 90% 以上中小商家的真实困境。
   - Shopro AI 将所有这些技能封装为「输入商品链接  输出视频」的单步操作，零学习成本。

3. **时效性陷阱（Timing Trap）**：
   - 传统视频制作周期 13 天，等视频做完，热点已过。
   - Shopro AI 将周期压缩至 5 分钟，让个体商家也能追热点、蹭流量，抓住 2472 小时的热点窗口。

4. **成本不可负担（Cost Barrier）**：
   - 传统视频制作 200800 元/条，中小商家平均单条预算不足 100 元。
   - Shopro AI 将边际成本压缩至 < 1 元/条，让个体商家每日更新成为可能。

### Q2：对该领域的独特市场认知或洞察

**洞察一：流量竞争的本质是内容生产效率的竞争，而非内容质量的竞争。**

在抖音 / TikTok 的算法逻辑下，账号权重、粉丝画像、互动率共同决定流量池大小。对于新账号和小商家而言，**持续产出足够多的合格内容远比产出几条精品内容更重要**。Shopro AI 的批量生成能力，恰恰解决了「数量」这个被绝大多数工具忽略的核心问题。

大多数 AI 视频工具（如 Runway、Pika）追求单条视频的艺术性和视觉冲击力，但电商场景下，用户 3 秒划走的决策依据不是画面精不精美，而是这个产品能不能解决我的问题。Shopro AI 从 URL 提取卖点、生成脚本的第一步起，就锚定转化率而非观赏性。

**洞察二：电商视频的核心不是好看，而是卖货。**

当前市场上大量 AI 视频工具以视觉效果为卖点，但电商场景下，用户 3 秒划走的决策依据不是画面精不精美，而是这个产品能不能解决我的问题。Shopro AI 从 URL 提取卖点、生成脚本的第一步起，就锚定转化率而非观赏性，这是根本性的产品哲学差异。

**洞察三：超级个体不是个人英雄主义，而是工具赋能下的组织效率重构。**

我们观察到，很多个体商家并非能力不足，而是缺乏工具和组织。Shopro AI 将五人团队（编剧 + 剪辑 + 翻译 + 模特 + 运营）的工作流压缩为一人 + 一个浏览器，本质上是将组织成本归零，让个体具备组织级的产出能力。

**洞察四：AIGC 在电商视频领域的渗透率正处于从 25% 向 60% 跃迁的拐点。**

2025 年 AIGC 在电商内容生产中的渗透率已超过 25%，预计 2027 年达到 60% 以上。Shopro AI 选择在渗透率拐点期切入，既能享受教育成本降低的红利，又能在用户心智中占据「电商 AIGC 首选」的心智锚点。

### Q3：解决方案与现有方案的本质差异

| 维度 | 传统视频制作 | 基础 AI 视频工具（Runway / Pika） | 数字人 SaaS（硅语 / 闪剪） | Shopro AI |
|---|---|---|---|---|

| **数据闭环** | 人工统计 | 无 | 无 | **AB 测试 + 转化追踪 + 自动优化** |
| **成本结构** | 200800 元/条 | 订阅制 + 算力费 | 订阅制 | **< 1 元/条 + 轻量订阅** |
| **使用门槛** | 专业团队 | 需要 prompt 工程能力 | 需要脚本能力 | **零基础，输入 URL 即可** |
| **分发能力** | 人工上传 | 无 | 无 | **一键分发至抖音 / 快手 / 小红书 / TikTok** |
| **批量能力** | 不可规模化 | 单条生成 | 单条生成 | **批量导入 100 个商品  100 条视频** |

**本质差异一句话总结**：

> Shopro AI 不是 AI 视频工具，而是 **AI 电商视频产能工厂**。

### Q4：项目的不可替代性

Shopro AI 的护城河由三层结构组成，每一层都难以在短期内被复制：

**第一层：数据飞轮（Data Moat）**

- 每次商家使用商品 URL 生成视频，都在丰富我们的「电商 URL  爆款脚本」映射数据库；
- 随着数据量增长，AI 生成的脚本转化率持续提升，形成正向循环；
- 冷启动阶段通过种子商家积累数据，成熟阶段数据成为最深的护城河竞品可以复制工具，但无法复制我们已经积累的电商领域微调数据。

**第二层：工作流专利（Workflow Moat）**

- 已规划 2 项发明专利：
  1. 基于多模态大模型的商品卖点自动提取与短视频分镜生成方法；
  2. 高并发数字人带货视频异步混剪调度系统。
- 端到端闭环的工作流（URL  脚本  数字人  翻译  混剪  分发）涉及 10+ 数据表、10+ Edge Functions 的深度耦合，竞品难以在 612 个月内复制同等深度。

**第三层：生态绑定（Ecosystem Moat）**

- 与头部 ERP（聚水潭、旺店通）的代运营服务商达成联合推广意向，OpenAPI 接口已设计完成，一旦接入第三方系统，切换成本极高；
- 微信支付闭环已验证，支付渠道本身具备一定排他性；
- 视频生成任务通过异步队列 + SSE 推送实现，前端 15+ 页面与后端 10+ Edge Functions 深度耦合，形成复杂的系统级壁垒。

### Q5：商业模式及当前已取得的验证数据

**商业模式核心公式**：

`
利润 = (SaaS 订阅收入 + 积分消耗收入 + OpenAPI 收入 + 定制部署收入)
       - (AI API 成本 + 云服务成本 + 人力成本 + 市场成本)
`

**关键验证数据**：

1. **技术可行性已验证**：
   - 前端 15+ 页面开发完成，代码量 > 5 万行，覆盖从官网宣传到视频剪辑的全流程；
   - 后端 10+ Edge Functions 部署上线，支付、AI、视频生成全链路调通；
   - 系统通过 Windows / Mac / iOS / Android 全终端兼容性测试。

2. **商业可行性已验证**：
   - 微信支付创建订单  回调  积分到账全流程跑通，零 bug；
   - 灰度内测 30+ 商家，核心功能使用率 > 80%；
   - 与数家头部电商代运营服务商达成联合推广意向，首批渠道已锁定。

3. **单位经济模型（UE）验证**：
   - 单条视频 AI API 成本：约 0.30.8 元；
   - 单条视频售价（按积分折算）：约 0.51.5 元；
   - 单条视频毛利：约 **5070%**；
   - SaaS 订阅边际成本趋近于零，用户规模越大，毛利率越高。
