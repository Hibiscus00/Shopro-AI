# 需求文档

## 1. 应用概述

### 1.1 应用名称
电商AIGC带货视频生成系统

### 1.2 应用描述
面向抖音/TikTok/快手/小红书等跨境电商商家的AI驱动带货视频生成工具，通过「商品输入→AI脚本生成→数字人克隆→多语言翻译→分镜编辑→批量生成→多平台发布」的端到端闭环，帮助商家快速产出符合平台风格、高转化潜力的带货短视频，降低视频制作成本，提升流量获取效率。Web端完全适配桌面端与移动端。

## 2. 用户与使用场景

### 2.1 目标用户
抖音/TikTok/快手/小红书跨境电商商家，缺乏专业视频剪辑和文案撰写能力，需要快速、低成本产出带货视频。

### 2.2 核心使用场景
- 商家需要快速制作带货视频响应平台流量热点
- 商家希望降低视频制作成本，无需雇佣专业剪辑师

- 商家需要判断视频流量潜力并优化视频效果

- 商家需要选择合适的数字人和视频模板提升视频效果
- 商家需要了解套餐权益和积分消费情况

- 商家需要复刻爆款视频风格应用到新视频中
- 商家需要诊断视频流量表现并获得优化建议
- 商家需要系统持续学习优化AI生成效果
- 潜在用户需要了解产品价值并快速进入系统使用
- 商家需要注册账号并找回密码
- 商家需要实时查看视频生成进度
- 商家需要批量导入商品信息

- 商家需要通过语义检索历史知识

#### 3.2.5 视频生成页

**步骤导航**
- 显示步骤导航：商品信息→AI智能脚本生成→数字人选择/克隆→多语言翻译→Prompt配置→智能分镜编辑→素材混剪→生成视频
- 支持返回修改之前步骤的内容
- 移动端步骤条优化：采用横向滚动或折叠展示，确保小屏幕可用性

**商品信息录入**
- 填写商品名称、核心卖点、品类
- 填写目标用户描述
- 选择目标语言（英语、日语、韩语、泰语、越南语等）
- 选择目标平台（抖音/TikTok/快手/小红书）
- 自动生成3条核心卖点
- 表单实时校验，必填项未填写时无法进入下一步
- 草稿自动保存至本地存储
- 新增「URL一键提炼卖点」功能：
  + 用户输入商品详情页URL
  + 系统调用web-reader提取页面内容
  + 调用文心大模型（wenxin-text-generation）自动提炼核心卖点
  + 提炼结果自动填充至核心卖点字段

**AI智能脚本生成**
- 基于商品信息通过四层Prompt流水线顺序调用LLM生成结构化分镜脚本
- 四层流水线：商品信息提取→目标用户画像分析→核心卖点提炼→分镜脚本生成
- 每层调用独立API请求，顺序执行
- 分镜脚本包含：场景描述、画面描述、台词文案、时长建议
- 自动生成用于驱动图像/视频生成的详细Prompt文案
- 支持用户手动编辑分镜脚本和Prompt文案
- 提供「重新生成」按钮，允许用户重新生成脚本
- 显示生成进度提示
- 支持流式SSE输出，实时展示生成内容
- 提供「取消生成」按钮，允许用户中止正在进行的AI生成任务
- 草稿自动保存至本地存储

**数字人选择/克隆**
- 展示数字人库列表，用户选择已有数字人
- 提供「克隆数字人」功能：
  + 用户上传照片或视频片段
  + 系统调用数字人克隆API生成数字人模型
  + 显示克隆进度提示
  + 克隆完成后自动添加至数字人库
- 预览数字人效果
- 草稿自动保存至本地存储

**多语言翻译**
- 展示当前脚本文案
- 用户选择目标语言（英语、日语、韩语、泰语、越南语等）
- 点击「一键翻译」按钮
- 系统调用翻译API将脚本文案翻译为目标语言
- 显示翻译进度提示
- 翻译完成后展示翻译结果
- 支持用户手动编辑翻译结果

**Prompt配置**

- Prompt预览
- 提供「取消生成」按钮，允许用户中止正在进行的AI生成任务

## 4. 业务规则与逻辑

### 4.1 视频生成流程
- 商品信息录入→AI智能脚本生成→数字人选择/克隆→多语言翻译→Prompt配置→智能分镜编辑→素材混剪→视频生成，形成完整闭环
- 每个步骤支持返回修改
- 视频生成采用异步处理，避免页面卡顿
- 视频生成任务派发至任务队列，通过实时推送接收进度更新
- 素材混剪和视频生成步骤增加流式日志加载与骨架屏，缓解用户等待焦虑

### 4.2 AI Agent自动脚本生成
- 根据商品名称、核心卖点、目标用户等基础信息通过四层Prompt流水线顺序调用LLM生成结构化分镜脚本
- 四层流水线：商品信息提取→目标用户画像分析→核心卖点提炼→分镜脚本生成
- 每层调用独立API请求，顺序执行
- 分镜脚本包含场景、画面描述、台词、时长建议
- 自动生成用于驱动图像/视频生成的详细Prompt文案
- 支持用户手动编辑生成结果
- 用户修改后的脚本和Prompt将回写至知识库
- 支持流式SSE输出，实时展示生成内容
- 提供20+内置电商场景Prompt模板供选择
- LLM响应缓存24小时，提升生成效率

### 4.3 数字人克隆规则
- 用户上传照片或视频片段
- 系统调用数字人克隆API生成数字人模型
- 克隆完成后自动添加至数字人库
- 数字人模型可在视频生成流程中调用

### 4.4 多语言翻译规则
- 支持目标语言：英语、日语、韩语、泰语、越南语等
- 系统调用翻译API将脚本文案翻译为目标语言
- 翻译结果支持用户手动编辑
- 翻译后的文案用于视频生成

### 4.5 智能分镜编辑规则
- 可视化分镜脚本编辑器
- 支持拖拽调整分镜顺序
- 支持手动增删改镜头
- 提供「AI自动分镜」功能，系统根据脚本自动生成分镜

### 4.6 批量生成规则
- 支持批量导入商品或从商品管理页选择多个商品
- 统一配置或为每个商品单独配置
- 系统创建批量生成任务并派发至任务队列
- 展示批量生成进度列表
- 支持暂停/恢复/取消批量生成任务

### 4.7 竞品爆款分析规则
- 用户输入竞品账号名称或链接
- 系统自动抓取竞品账号的爆款视频列表
- 调用AI分析API分析竞品爆款视频策略
- 生成分析报告（视频风格特点、内容策略、发布策略）
- 基于竞品策略结合商品信息生成对标视频预览

### 4.8 数据看板规则
- 展示关键指标：总播放量、总转化率、总ROI、总视频数
- 展示趋势图表（播放量、转化率、ROI）
- 展示视频排行榜（播放量Top10、转化率Top10、ROI Top10）
- 展示平台数据对比（抖音/TikTok/快手/小红书）

### 4.9 多平台发布规则
- 支持平台：抖音、快手、小红书、TikTok
- 用户勾选需发布的平台
- 填写视频标题、描述、标签
- 选择发布时间（立即发布/定时发布）
- 系统调用各平台发布API
- 展示发布结果（成功/失败、失败原因）

### 4.10 爆款视频风格复刻
- 支持输入抖音/TikTok/快手/小红书爆款视频公开链接或直接上传视频文件
- 调用真实多模态分析API提取视频风格
- 自动提取视频风格：节奏、转场、字幕样式、BGM类型
- 生成可视化风格分析报告
- 基于分析风格结合商品信息生成新视频预览
- 复刻风格应用到新生成视频中

### 4.11 流量诊断与优化
- 基于视频特征（总时长、节奏分布、字幕覆盖率）+ 商品信息 + 脚本内容进行分析
- 调用真实流量分析API获取预测数据
- 预测关键流量指标：完播率、互动率（点赞/评论/分享）
- 提供具体可执行优化建议
- 「一键优化」功能：系统根据诊断建议自动调整脚本或Prompt并重新生成视频
- 优化前后对比预览（展示真实对比数据：优化前后的完播率、互动率变化）

### 4.12 知识反馈与系统进化
- 收集商家手动修改后的最终版分镜脚本和Prompt文案
- 收集商家对优化建议的采纳与反馈
- 将有效数据回写至系统知识库

- 系统提示知识库已更新
- 用户在后续任务中感受到AI生成效果逐步优化
